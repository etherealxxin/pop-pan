# Popcorn Game

Shake the pan over the fire and pop at least 70% of the kernels before time runs out — without burning them.

Everything lives in a single file, `index.html`. Open it in a browser to play.

## How to play

- **Desktop:** drag the pan with the mouse (or use the arrow keys) to keep it over the flame and shaking.
- **Phone:** shake the phone itself to shake the pan; drag to move it. Motion sensors only work over HTTPS (e.g. GitHub Pages).
- Stay on the fire to cook, keep shaking so nothing burns, and don't shake so hard that popcorn flies out (Lv.4+).
- 5 levels; clear them all for the All Clear screen. Best stars are saved in the browser.
